# Hive feedback

Ideas, bugs and search feedback for [Hive](https://hive.afore.vc), the Afore founder network.

This repo has no code, just issues. Anyone with a GitHub account can see them.

## How to give feedback

[Open an issue](../../issues/new/choose) and pick a form:

- **Search results** — a search that found the wrong people, or missed the right ones. These become test cases for Hive's search.
- **Bug** — something broke or didn't work as expected.
- **Idea** — a feature or change that would make Hive more useful.

Add a 👍 to an existing issue instead of opening a duplicate.

## Keep it private

Issues here are public. Please **don't post screenshots of search results, people's names or anything about your company you wouldn't post publicly.** Describe the search and what was wrong instead.

For anything private, DM Aaron on Slack or use the **Feedback** button in Hive.
